02 / 03 · CASE STUDY

Eliminating Lambda database connection bottlenecks

Problem: Serverless functions opening many database connections created bottlenecks on Aurora PostgreSQL under concurrent load.

API Gateway → Lambda (Java) → RDS Proxy → Aurora PostgreSQL

Tech stack: Java · AWS Lambda · API Gateway · RDS Proxy · Aurora PostgreSQL

Trade-offs: RDS Proxy adds cost and a network hop, but gives reliable connection pooling that per-function pooling cannot provide across Lambda instances.

Results: Removed connection bottlenecks and improved query execution times.
